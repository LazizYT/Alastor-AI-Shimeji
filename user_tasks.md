## ⚡ 1. Проверить горячие клавиши (Прямо сейчас!)

Я обновил механизм хоткеев в коде на нативный Windows Win32 API. Теперь клавиши срабатывают мгновенно и **не зависят от русской или английской раскладки клавиатуры**.

- [ ] **Нажмите клавишу `F8`** (самая удобная клавиша для быстрого вызова в 1 клик).
  - *Что должно произойти:* над Аластором появится облачко: *«Шоу в эфире! Слушаю вас... (говорите в микрофон)»*, и Аластор возьмет гитару/микрофон.
- [ ] **Или нажмите комбинацию `Ctrl + Shift + V`** (или `Ctrl + Alt + A`).
- [ ] Попробуйте сказать простую команду, например:
  - *«Открой ютуб»*
  - *«Запусти калькулятор»*
  - *«Найди в гугле погоду»*

> **Примечание:** Если Аластор был запущен ранее, перезапуск уже произошел автоматически в фоне с новым кодом.

## 🔑 2. Получить бесплатный ключ Google Gemini API

Для того чтобы Аластор мог не просто открывать сайты, но и полноценно общаться в чате своим острым и харизматичным умом, нужен API-ключ Gemini 1.5 Flash (он бесплатный):

1. Перейдите на официальный сайт: **[https://aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)**.
2. Войдите под своим Google-аккаунтом.
3. Нажмите синюю кнопку **«Create API key»** (Создать ключ API).
4. Скопируйте полученный ключ (начинается с `AIzaSy...`).
5. Вставьте его в программу:
   - Кликните правой кнопкой мыши по Аластору -> выберите **«🤖 Спросить Аластора (ИИ-чат)»**.
   - В поле **«Gemini API Key:»** вставьте ключ и нажмите **«Сохранить»**.

## 🎙️ 3. Проверить микрофон в Windows

Чтобы распознавание речи работало чётко и без задержек:

1. Откройте **Параметры Windows** -> **Система** -> **Звук** -> раздел **Ввод**.
2. Убедитесь, что ваш основной рабочий микрофон выбран как **«Устройство по умолчанию»**.
3. Скажите пару слов — синяя полоска громкости должна реагировать на голос.

## 🎵 4. (Для Фазы 2) Установка FFmpeg (для скачивания музыки и видео)

Для работы будущего инструмента скачивания треков и видео с YouTube (`yt-dlp`) в Windows понадобится утилита `ffmpeg`.

Самый простой способ установить её одной командой в консоли:
1. Нажмите клавиши `Win + X` -> выберите **Терминал (или PowerShell)**.
2. Вставьте и запустите команду:
   ```powershell
   winget install Gyan.FFmpeg
   ```
3. После завершения перезагрузите терминал. (Если возникнут трудности — напишите мне, я помогу настроить автоматически).
